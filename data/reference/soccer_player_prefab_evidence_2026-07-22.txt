## Verdict

Soccer players are the prefab **`AIALander - Soccer`** in `sharedassets0.assets`. Movement is **Rigidbody + CapsuleCollider + NavMeshAgent + `DeterministicMover`** — **no `CharacterController` anywhere** in `sharedassets0` or `level0`. Walk/sprint numerics and interact-radius **value** are not named in scrapable assets; they sit in opaque `MonoBehaviour` payloads / IL2CPP code. Saves expose **`Player Interact Radius`** and **`Ball Velocity`** only — **no player speed/velocity/acceleration labels**.

### Possession / auto-capture (inference + bot evidence)

From AIA graph design (`AIATest_readable.py` / overview):
- **`Player Interact(ready, ballNearby, hasBall)`** drives the **interact** controller bit
- **`Is Ball Nearby`** and **`Has Ball`** are separate
- Sprint/chase use **`Is Ball Loose`** + **`Player Interact Radius`** for proximity

From assets/tooltips:
- Explicit **pickup/tackle** language and post-shot **re-pickup cooldown**
- **`TouchRecord`** ≠ automatic possession

**Conclusion:** Static data strongly indicates **interact (and tackle/stamina rules) gate possession**, not “any touch = own ball.” Exact touch→possession branching is **only in `SoccerPlayer` / `SoccerBall` / `SoccerGameManager` IL2CPP code** (not statically readable here).

Tackle rule (from project docs/API dump, not asset floats): stamina delta; tackler wins if more stamina **after** tackle.

## 6. What cannot be statically scraped (lives in MonoBehaviour / IL2CPP)

| Topic | Why blocked |
|-------|-------------|
| Confirmed **walk / sprint / accel** field names & which float is which | `SoccerPlayer` / `DeterministicMover` type trees fail; **global-metadata encrypted** (`Il2CppDumper`: “Metadata file not found or encrypted”); no `MelonLoader/Il2CppAssemblies` dump yet |
| Numeric **`Player Interact Radius`** | Runtime getter only; label in graphs, value not in assets as a named constant |
| Whether **collision alone** captures the ball | Logic in `SoccerPlayer`/`SoccerBall` code |
| Sprint **multiplier** vs absolute sprint speed | Unlabeled floats only |
| When NavMeshAgent.speed is assigned | Runtime (`DeterministicMover` / `SoccerPlayer`) |
| Dropdown option arrays on `SoccerGet*` UI nodes | MonoBehaviour payloads not deserializable; labels recovered from **saves**, not prefab option lists (`worldcup_soccer_mined.json` `option_hits: {}`) |
